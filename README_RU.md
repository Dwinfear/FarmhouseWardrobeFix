# Farmhouse Wardrobe Fix 1.0.0

[English version](README_EN.md)

Мод для **The Long Dark**, исправляющий заблокированную секцию гардероба в
фермерском доме Приятной долины (`FarmHouseA`) и оставшуюся от неё запечённую
тень. Дополнительно позволяет навсегда скрывать выбранные декоративные объекты
и повторно применять эти удаления при загрузке сцены.

Автор: **Dwinfear + ChatGPT**

## Возможности

- Автоматически скрывает проблемный `OBJ_DresserTallDrawerD` в `FarmHouseA`.
- Точечно исправляет его тень в оригинальной `Lightmap-1_comp_light`.
- Не заменяет всю карту освещения: изменяются только восемь BC7-регионов.
- По назначенной клавише (`F4` по умолчанию) скрывает объект под прицелом.
- Сохраняет выбранные объекты в `FarmhouseWardrobeFix.json`.
- Различает одинаковые объекты по сцене, пути, имени и мировой позиции.
- Позволяет переназначить клавишу через Mod Settings или вручную в JSON.
- При нормальной работе не засоряет консоль служебными сообщениями.

Проблемный гардероб встроен в мод и в JSON не записывается. Массив
`RemovedObjects` содержит только объекты, которые выбрал пользователь.

## Требования

- The Long Dark для Windows.
- MelonLoader с поддержкой .NET 6.
- ModSettings.
- Direct3D 11 для исправления запечённой тени.

Если игра запущена через другой графический API или структура lightmap не
совпадает с ожидаемой, исправление тени безопасно остановится и запишет ошибку
в журнал. Удаление гардероба и пользовательских объектов от этого не зависит.

## Установка

Готовый релиз состоит из одного файла:

```text
FarmhouseWardrobeFix.dll
```

Скопируй его в:

```text
TheLongDark\Mods
```

Внешние файлы `farmhouse_lightmap_regions.fwbc7`,
`farmhouse_lightmap.bundle` и `farmhouse_lightmap_patched.bc7` не требуются:
патч встроен в DLL.

## Управление

1. Наведи центр экрана на отдельный предмет или декоративный объект.
2. Нажми назначенную клавишу — по умолчанию `F4`.
3. Объект исчезнет и будет добавлен в JSON.
4. При следующей инициализации этой сцены мод снова скроет именно этот экземпляр.

Сменить клавишу можно в:

```text
Настройки -> Mod Settings -> Farmhouse Wardrobe Fix
```

Значение `None` отключает горячую клавишу, но сохраняет уже записанные удаления.

Мод блокирует удаление корней сцены, пола, игрока и основных системных объектов.

## Конфигурация

При первом запуске создаётся файл:

```text
TheLongDark\Mods\FarmhouseWardrobeFix.json
```

Пример:

```json
{
  "RemovalKey": "F4",
  "RemovedObjects": [
    {
      "Scene": "FarmHouseA",
      "Path": "Root/Art/Structure/Electrical/OBJ_LampE_Prefab",
      "Name": "OBJ_LampE_Prefab",
      "PositionX": -8.435,
      "PositionY": 1.652,
      "PositionZ": 1.05
    }
  ]
}
```

`RemovalKey` можно изменить вручную при закрытой игре. Используй имя из
`UnityEngine.KeyCode`, например `F5`, `Delete` или `Keypad0`.

Чтобы вернуть пользовательский объект:

1. Закрой игру.
2. Удали его запись из `RemovedObjects`.
3. Сохрани JSON и снова войди в сцену.

## Производительность

Мод не выполняет постоянный поиск объектов и не обновляет lightmap бесконечно:

- встроенный гардероб находится прямым `GameObject.Find` только при
  инициализации сцены;
- полный список `Transform` запрашивается только при загрузке сцены и только
  если для неё существуют пользовательские записи в JSON;
- JSON читается один раз при запуске и записывается только после выбора объекта
  или подтверждения новой клавиши;
- BC7-патч применяется во время короткой стартовой загрузки mip-уровней;
- после появления полной текстуры 2048×2048 мониторинг lightmap полностью
  отключается;
- в обычном игровом кадре остаются проверка назначенной клавиши и одна дешёвая
  проверка флага стартового мониторинга; сканирований и записей больше нет.

Исходный BC7-патч занимает около 30 КБ, а готовый мод не создаёт фоновых потоков,
корутин или периодических сканирований сцены.

## Сборка

Полностью закрой игру, открой PowerShell в корне проекта и выполни:

```powershell
.\build.ps1
```

При нестандартном расположении игры:

```powershell
.\build.ps1 -TLDPath "D:\Games\TheLongDark"
```

Готовая DLL появится в `Go`.

## Архитектура

- `WardrobeFixMod` принимает события MelonLoader и связывает компоненты.
- `ConfigStore` отвечает только за чтение, проверку и запись JSON.
- `ObjectRemovalService` обслуживает встроенный гардероб и пользовательские
  удаления.
- `AimedObjectResolver` изолирует raycast, выбор корня префаба и защиту
  системных объектов.
- `LightmapPatchService` проверяет нужную lightmap и ограничивает работу
  стартовым периодом загрузки текстуры.
- `NativeBc7Patch` проверяет формат встроенного патча.
- `D3D11Bc7RegionWriter` изолирует небезопасную низкоуровневую запись BC7.

Мод не изменяет файл сохранения The Long Dark и не уничтожает игровые ресурсы:
выбранные GameObject только отключаются на время загруженной сцены.

## Журнал

При штатной работе мод молчит. В `MelonLoader/Latest.log` остаются только
предупреждения о неправильной цели или конфигурации и ошибки проверки lightmap,
BC7 или Direct3D 11.
